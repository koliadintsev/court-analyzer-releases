# CourtAnalyzer — аналіз судових рішень з ЄДРСР

Програма для Windows і macOS. Вона бере перелік рішень, знайдених на сайті reyestr.court.gov.ua, знаходить їх у відкритих даних реєстру, завантажує тексти, відсіює нерелевантні рішення за допомогою ШІ, витягує потрібні дані та зберігає таблицю в Excel.

## Завантаження і встановлення

Остання версія — на сторінці **[Releases](../../releases/latest)**:

- **Windows** — файл **`CourtAnalyzer-1.0.0.exe`** (~7 МБ);
- **macOS** — файл **`CourtAnalyzer-1.0.0-arm64.dmg`** (~3 МБ), для Mac з процесором Apple (M1 і новіші) і macOS 11 або новішою. Mac з процесором Intel наразі не підтримуються.

### Windows

Встановлювати нічого не потрібно. Покладіть файл у будь-яку папку і запустіть подвійним кліком.

Для роботи потрібен компонент Microsoft Edge WebView2. Він уже вбудований у Windows 11 і в оновлену Windows 10.

Програма не має цифрового підпису, тому Windows може показати вікно «Windows захистив ваш ПК». Натисніть **«Докладніше» → «Виконати в будь-якому разі»**.

Поруч із програмою з'явиться папка **`CourtAnalyzer-data`**. У ній зберігаються налаштування, профілі, архіви реєстру (~350 МБ за кожен рік), тексти рішень, кеш відповідей ШІ та результати запусків. Щоб перенести програму на інший комп'ютер, скопіюйте її разом із цією папкою. API-ключі доведеться ввести заново: вони зашифровані для конкретного користувача Windows.

### macOS

1. Відкрийте завантажений файл `.dmg` і перетягніть **CourtAnalyzer** у папку **«Програми»** (Applications).
2. Запустіть програму з папки «Програми» або через Launchpad.

Програма не має цифрового підпису Apple, тому під час першого запуску macOS повідомить, що не може перевірити розробника. Дозволити запуск потрібно лише один раз:

- **macOS 15 (Sequoia) і новіші.** Спробуйте відкрити програму і в повідомленні натисніть «Готово» (Done). Потім відкрийте **Системні параметри → Приватність і безпека** (System Settings → Privacy & Security), прогорніть донизу до розділу «Безпека» і біля повідомлення про CourtAnalyzer натисніть **«Усе одно відкрити»** (Open Anyway). Підтвердіть паролем або Touch ID.
- **macOS 11–14.** У Finder клацніть програму правою кнопкою миші (або з натиснутою клавішею Control), виберіть **«Відкрити»** (Open) і ще раз натисніть **«Відкрити»** у вікні попередження.

Якщо macOS пише, що програму «пошкоджено» і її не можна відкрити, виконайте в Терміналі цю команду і запустіть програму знову:

```bash
xattr -dr com.apple.quarantine /Applications/CourtAnalyzer.app
```

На Mac робоча папка не лежить поруч із програмою, а розташована в `~/Library/Application Support/com.lexcovery.courtanalyzer/data`. Відкрити її можна кнопкою **«Відкрити папку»** у розділі **«Дані реєстру» → «Робоча папка»**. У ній зберігаються ті самі дані, що й у Windows: налаштування, профілі, архіви реєстру (~350 МБ за кожен рік), тексти рішень, кеш відповідей ШІ та результати запусків.

API-ключі шифруються, а ключ шифрування зберігається у в'язці ключів macOS (Keychain). Після встановлення нової версії програми macOS може один раз запитати дозвіл на доступ до в'язки ключів: введіть пароль користувача Mac і натисніть **«Завжди дозволяти»** (Always Allow). Якщо відмовити, збережені API-ключі доведеться ввести заново.

- **Оновлення.** Перетягніть нову версію в «Програми» із заміною. Налаштування і дані зберігаються окремо від програми й не втрачаються.
- **Перенесення на інший Mac.** Скопіюйте робочу папку в те саме місце на іншому Mac. API-ключі доведеться ввести заново: вони зашифровані для конкретного користувача macOS.
- **Видалення.** Перетягніть програму з «Програм» у Кошик. Щоб видалити й дані, видаліть папку `~/Library/Application Support/com.lexcovery.courtanalyzer`, а в програмі «Доступ до в'язки ключів» (Keychain Access) — запис `com.lexcovery.courtanalyzer`.

## Порядок роботи

1. **Налаштування ШІ** (пункт меню ⚙). Оберіть провайдера — OpenAI, Anthropic (Claude), Google Gemini або OpenAI-сумісний (OpenRouter, локальні Ollama / LM Studio). Окремо задайте модель для ШІ-фільтра (простішу й дешевшу) і для витягу даних (потужнішу). Вставте свій API-ключ і натисніть «Зберегти». Після цього програма сама запитає в провайдера список доступних моделей, і модель можна буде вибрати зі списку.
2. **Перелік рішень.** Знайдіть рішення на reyestr.court.gov.ua за ключовими словами. Потім:
   - на сторінці результатів натисніть `Ctrl+A`, `Ctrl+C` (на Mac — `Cmd+A`, `Cmd+C`) і вставте текст у поле програми, **або**
   - збережіть сторінку результатів (`Ctrl+S`, на Mac — `Cmd+S`) і завантажте HTML-файл; можна кілька файлів, якщо результатів кілька сторінок. У Safari в полі «Формат» виберіть **«Джерело сторінки»** (Page Source), а не «Вебархів» (Web Archive), **або**
   - завантажте TXT/CSV/XLSX з номерами рішень або посиланнями `https://reyestr.court.gov.ua/Review/…`.

   Перелік можна доповнювати з кількох джерел — повтори програма прибирає сама.
3. **Фільтри.**
   - *Формальні* — працюють за даними реєстру: форма рішення, вид судочинства, інстанція, період ухвалення, мінімальна довжина тексту.
   - *ШІ-фільтр* — опишіть тему своїми словами, наприклад «рішення стосується стягнення неустойки за договором поставки». ШІ прочитає кожне рішення і залишить тільки релевантні.
4. **Поля таблиці.** Позначте потрібні колонки і розставте їх у потрібному порядку стрілками ↑↓.
   - Колонки «з реєстру» (дата, номер справи, суд, інстанція тощо) беруться з відкритих даних.
   - Колонки «ШІ» заповнює модель. Для кожної колонки задайте назву, інструкцію (що саме знайти) і тип: текст, розгорнутий текст, список, так/ні, число, дата або вибір з варіантів.
5. **Запуск і результати.** Натисніть «Запустити обробку». Хід виконання видно по етапах. Після завершення натисніть «Зберегти в Excel…».

   Файл Excel містить три аркуші:
   - **Результати** — таблиця з обраними колонками;
   - **Відхилені** — рішення, що не пройшли фільтри, і причина відхилення;
   - **Параметри** — модель, критерії та дата запуску.

## Профілі аналізу

Фільтри, поля таблиці та інструкції для ШІ зберігаються в **профілі**. Профіль вибирається вгорі вікна. Вбудований шаблон **«Базовий аналіз судових рішень»** підходить для будь-якої теми: сторони, предмет спору, сума вимог, результат розгляду, на чию користь, ключові норми, правова позиція суду, суть справи, ключові слова. Додатково можна ввімкнути доводи сторін, рішення попередніх інстанцій і посилання на практику. ШІ-фільтр у ньому вимкнено: щоб відбирати рішення за темою, увімкніть його на сторінці «Фільтри» і опишіть тему.

Через меню «Дії з профілем» можна створити новий профіль з шаблону, зробити копію, перейменувати профіль, експортувати його в JSON-файл, щоб передати колезі, та імпортувати такий файл. Усі зміни зберігаються автоматично.

## Дані реєстру і нові роки

ДСА публікує відкриті дані ЄДРСР окремим архівом за кожен рік. Програма знаходить набори автоматично через портал data.gov.ua і завантажує лише ті архіви, що потрібні для вашого переліку. Завантажені архіви раз на тиждень звіряються з сервером і оновлюються, якщо на сервері є новіша версія.

Якщо набір за новий рік ще не знайдено автоматично, відкрийте розділ **«Дані реєстру» → «Додати набір вручну»** і вставте посилання на набір (сайт ДСА, data.gov.ua або пряме посилання на ZIP) чи виберіть уже завантажений ZIP-архів.

## Кеш і повторні запуски

Тексти рішень і відповіді ШІ зберігаються на диску. Якщо зупинити обробку або виникне збій, просто запустіть її ще раз: уже оброблені рішення повторно не надсилаються до ШІ і не оплачуються. Усі попередні запуски зберігаються в пункті меню **«Історія запусків»**.

## Конфіденційність і вартість

API-ключі зберігаються лише на вашому комп'ютері, у зашифрованому вигляді (у Windows — засобами Windows, на Mac — з ключем у в'язці ключів macOS). Тексти рішень надсилаються тільки обраному провайдеру ШІ. Оплата за використання ШІ йде напряму провайдеру за вашим ключем.

## Типові повідомлення

| Статус | Що означає |
|---|---|
| Не знайдено у відкритих даних | Відкриті дані оновлюються раз на добу, тож рішення останніх днів можуть ще не потрапити до архіву. Також причиною може бути неправильний номер або відсутній набір за потрібний рік. |
| Немає тексту | Текст рішення не оприлюднено (наприклад, обмежений доступ). |
| Закороткий текст | Текст коротший за мінімальну довжину з фільтрів. Зазвичай це процесуальні ухвали. |
| Не стосується теми | ШІ-фільтр визнав рішення нерелевантним. Причину видно в деталях рішення та на аркуші «Відхилені». |
| HTTP 429 | Перевищено ліміт запитів провайдера ШІ. Програма сама повторює запит. Якщо помилка повторюється, зменште «Паралельних запитів до ШІ». |

## Для розробника

Стек: Tauri 2 (Rust) + TypeScript + React (Vite). Інтерфейс і вся бізнес-логіка написані на TypeScript і працюють у вбудованому вебкомпоненті системи (WebView2 у Windows, WKWebView у macOS). Невеликий Rust-шар відповідає за файли, читання ZIP-архівів реєстру, завантаження з докачуванням і шифрування ключів (DPAPI у Windows, AES-256-GCM з ключем у в'язці ключів у macOS). Тому програма займає ~7 МБ, а не ~110 МБ, як попередня версія на Electron.

```
src-tauri/       Rust-шар: робоча папка, файли, ZIP (сканування, довідники, Range-проба), завантаження, DPAPI / Keychain
src/engine/      каталог років, конвеєр, ШІ-провайдери, промпти, RTF→текст, Excel; platform.ts — інтерфейс до Rust-шару
src/shared/      спільні типи, шаблони профілів, довідники
src/renderer/    інтерфейс (React); appApi.ts — зв'язка з двигуном, mock.ts — імітація для перегляду в браузері
tests/           юніт-тести (Node)
```

Чому не «просто сторінка в браузері»: сервери `court.gov.ua`, `data.gov.ua` і `od.reyestr.court.gov.ua` не надсилають заголовків CORS. Тому сторінка, відкрита в браузері, не може завантажити ні архіви, ні тексти рішень. У Tauri ці запити виконує Rust, де обмеження CORS немає.

Потрібні Node.js 22+ і Rust ([rustup](https://rustup.rs)), а також:

- для Windows — target `x86_64-pc-windows-msvc` і Visual Studio Build Tools з компонентом C++;
- для macOS — Xcode Command Line Tools (`xcode-select --install`).

Встановити залежності:

```bash
npm install
```

Запустити в режимі розробки (з автоматичним перезавантаженням інтерфейсу):

```bash
npm start
```

Переглянути інтерфейс у звичайному браузері з імітацією API:

```bash
npm run dev:ui
```

Юніт-тести TypeScript:

```bash
npm test
```

Тести Rust-шару:

```bash
npm run test:rust
```

Зібрати програму для Windows (`release/CourtAnalyzer-<версія>.exe`):

```bash
npm run dist
```

Зібрати програму для macOS (`release/CourtAnalyzer-<версія>-arm64.dmg`; сам `.app` — у `src-tauri/target/release/bundle/macos/`):

```bash
npm run dist:mac
```

Налаштування збірки для macOS — у `src-tauri/tauri.macos.conf.json`; Tauri враховує цей файл лише під час збірки на Mac. Програма підписується ad-hoc-підписом без нотаризації. Щоб macOS не показувала попередження під час першого запуску, потрібні сертифікат Developer ID і нотаризація Apple.

Змінні середовища:

- `COURT_ANALYZER_DATA` — інша робоча папка;
- `CA_PAGE` — сторінка, яка відкривається першою;
- `CA_TEST` — режим автоматичних перевірок;
- `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9223` — підключення DevTools/CDP для наскрізних перевірок (лише Windows).
